## Overview

This is an improvement to my first [Padel Racket keychain](https://makerworld.com/en/models/157283){: target="_blank"} model.

{% include figure popup=true image_path="/assets/images/projects/makerworld/padel-racket-keychain-v2/inline-0.jpg" alt="Padel racket keychain v2" %}

{% include figure popup=true image_path="/assets/images/projects/makerworld/padel-racket-keychain-v2/inline-1.jpg" alt="Padel racket keychain v2" %}
