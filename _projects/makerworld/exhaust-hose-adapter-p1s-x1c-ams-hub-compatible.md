## Overview

This is version 2 of my [**Exhaust Hose Adapter**](https://makerworld.com/en/models/156371-exhaust-hose-adapter-for-bambu-lab-p1s-80-mm-90deg){: target="_blank"}, redesigned to be fully compatible with the [**Bambu Lab AMS Hub**](https://eu.store.bambulab.com/products/ams-hub){: target="_blank"}.

🔧 **Key Improvements:**

- Resized to match AMS Hub dimensions
- Hose outlet now angled **upward** for better tube management
- Added a **screwdriver access hole** for easier installation
- The default print profile is for [PETG-HF material](https://eu.store.bambulab.com/products/petg-hf){: target="_blank"} using the [Support for PLA/PETG material](https://eu.store.bambulab.com/products/support-for-pla-petg){: target="_blank"} as the support interface

🛠️ **Installation Instructions:**

1. **Mounting:** Use the four **M3** mounting holes located beside the exhaust grid on the rear panel. Start by removing the pre-installed left screw. Then, attach the adapter using three additional M3 screws (top, bottom, and right).
1. **Sealing (Recommended):** For a tighter and more efficient seal, apply a soft tape along the adapter's border before securing it.
1. **Hose Connection:** Use a **3" (8 cm) flexible PVC exhaust tube**. Secure the hose with a **metal clamp** for a tight, reliable fit. The adapter’s integrated **ribbed design** reinforces the hose connection, helping the clamp grip securely and improving overall durability.

📐 **Customizable Design:** The original model is [publicly available on **OnShape**](https://cad.onshape.com/documents/47ea8acfee4e43ddcabd1b3e/w/89219b009a7c6a92777daff2/e/f5ebf9c426c9e037f9465a54?renderMode=0&uiState=681c8ec2a5712a4a9722f6a4){: target="_blank"}.
