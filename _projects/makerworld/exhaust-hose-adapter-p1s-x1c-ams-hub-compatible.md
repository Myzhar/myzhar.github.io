## Overview

This is version 2 of my [**Exhaust Hose Adapter**](/projects/makerworld/exhaust-hose-adapter-for-p1s-x1c-80-mm-90deg/), redesigned to be fully compatible with the [**Bambu Lab AMS Hub**](https://eu.store.bambulab.com/products/ams-hub){: target="_blank"}.

The original adapter worked well, but it was designed before the AMS Hub existed, and once I added the Hub to my own P1S the old adapter's footprint and hose routing no longer matched the new hardware around the back of the printer. Rather than leave the original design to slowly become obsolete, I went back into OnShape and reworked the whole thing around the AMS Hub's actual dimensions, so both pieces of hardware coexist cleanly instead of competing for the same space.

🔧 **Key Improvements:**

- Resized to match AMS Hub dimensions
- Hose outlet now angled **upward** for better tube management
- Added a **screwdriver access hole** for easier installation
- The default print profile is for [PETG-HF material](https://eu.store.bambulab.com/products/petg-hf){: target="_blank"} using the [Support for PLA/PETG material](https://eu.store.bambulab.com/products/support-for-pla-petg){: target="_blank"} as the support interface

🛠️ **Installation Instructions:**

1. **Mounting:** Use the four **M3** mounting holes located beside the exhaust grid on the rear panel. Start by removing the pre-installed left screw. Then, attach the adapter using three additional M3 screws (top, bottom, and right).
1. **Sealing (Recommended):** For a tighter and more efficient seal, apply a soft tape along the adapter's border before securing it.
1. **Hose Connection:** Use a **3" (8 cm) flexible PVC exhaust tube**. Secure the hose with a **metal clamp** for a tight, reliable fit. The adapter’s integrated **ribbed design** reinforces the hose connection, helping the clamp grip securely and improving overall durability.

📐 **Customizable Design:** The original model is [publicly available on **OnShape**](https://cad.onshape.com/documents/47ea8acfee4e43ddcabd1b3e/w/89219b009a7c6a92777daff2/e/f5ebf9c426c9e037f9465a54?renderMode=0&uiState=681c8ec2a5712a4a9722f6a4){: target="_blank"}. You’re welcome to modify it to suit your setup or preferences.
